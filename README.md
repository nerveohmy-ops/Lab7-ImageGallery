# Лабораторная работа 7 — «Приложения для просмотра изображений» (Галерея)

Простое приложение на **C# Windows Forms** (.NET 10) для просмотра изображений с управлением масштабом и режимом отображения.

## Реализованный функционал

### Основная часть
- Выбор каталога с изображениями через `FolderBrowserDialog` (кнопка **«Указать директорию»**).
- Отображение пути к выбранной директории в верхней панели (`label1`).
- Список найденных изображений (`.jpg`, `.jpeg`, `.png`, `.bmp`, `.gif`, `.webp`) в `ListBox`.
- Предпросмотр выбранного изображения в `PictureBox`.

### Самостоятельная часть
- **TrackBar** для изменения масштаба от `50%` до `200%` с шагом `10%`.
- **Label** для отображения текущего процента масштаба.
- **Кнопки управления размером**:
  - **«Увеличить (+10%)»**
  - **«Уменьшить (-10%)»**
  - **«Оригинальный размер (100%)»**
  - **«По размеру окна (Zoom)»**
- **ComboBox** для выбора режима `PictureBoxSizeMode`:
  - `Zoom` (масштабирование с сохранением пропорций)
  - `StretchImage` (растягивание)
  - `CenterImage` (по центру)
  - `Normal` (оригинальный размер)

## Запуск

```bash
dotnet build
dotnet run
```
